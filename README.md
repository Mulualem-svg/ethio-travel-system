# Ethio Travel System

A web-based intercity transport and fare system interface designed to streamline bus ticket booking and travel management in Ethiopia.

## 🚀 Overview

This repository contains the user interface and core application files for the Ethio Travel System. It includes all user and administrative screens required for browsing routes, booking trips, managing user accounts, and processing payments seamlessly.

## 🛠️ Tech Stack

* **HTML5** – Page structure and form layouts
* **CSS3** – Layout, styling, and custom UI design
* **JavaScript** – Frontend interactivity and backend runtime
* **Node.js (Express)** – Server-side logic (`server.js`) and routing
* **MySQL** – Database structure for managing travel data and user bookings (`database.sql`)

## 📂 Included Pages & Modules

* **index.html** – Main landing page for the travel system
* **login.html & register.html** – Authentication and user onboarding interfaces
* **booking.html** – Bus selection, route searching, and ticket booking UI
* **payment.html** – Integrated payment gateway interface (supporting services like Telebirr)
* **Ticket.html** – Display view for issued travel tickets
* **my_bookings.html** – User dashboard to track and review active bookings
* **dashboard.html** – User account and profile overview
* **Admin.html** – System administration portal for managing travel operations
* **server.js** – Node.js backend server handling application runtime and requests
