# Ethio Travel System

A web-based intercity transport and fare system interface designed to streamline bus ticket booking and travel management in Ethiopia.

## 🚀 Overview
This repository contains the user interface (frontend) for the Ethio Travel System. It includes all user and administrative screens required for browsing routes, booking trips, and managing user accounts.

## 🛠️ Tech Stack
* HTML5 - Page structure and forms
* CSS3 - Layout, styling, and UI design

## 📂 Included Pages
* index.html - Main landing page
* login.html & register.html - Authentication interfaces
* booking.html - Bus selection and ticket booking UI
* payment.html - Payment gateway interface
* Ticket.html - Issued travel ticket display
* dashboard.html - User account overview
* Admin.html - System administration portal
